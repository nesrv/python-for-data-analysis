Функция — именованный блок кода. Её вызывают по имени и передают аргументы. `return` отдаёт результат вызывающему коду. Без `return` функция возвращает `None`.

## 2.6.1. Определение и вызов

`def` создаёт функцию и связывает её с именем. Имя можно положить в другую переменную: вызывается тот же объект.

**Ячейка:**

```python
print("hello")
f = print
f("hello")
```

Обе строки печатают `hello`. `f` и `print` указывают на одну функцию.

**Ячейка — имя print занято:**

```python
f = print
print = "это была функция print"
f(print)
print = f
```

После присваивания имя `print` — строка, а функция печати жива под именем `f`. Последняя строка возвращает имя `print` функции, иначе следующие ячейки не смогут печатать.

**Критерий 2.6.1:** второй вызов `f` печатает текст `это была функция print`. После последней строки `print(1)` снова печатает число.

## 2.6.2. Параметры и return

Параметры — имена внутри функции. Аргументы — значения в вызове.

**Ячейка:**

```python
def sum2(a, b):
    c = a + b
    return c

result = sum2(5, 2)
print(result)
result = sum2(sum2(4, -2), 7) + 12
print(result)
```

Сначала выполняется внутренний вызов `sum2(4, -2)`, он возвращает `2`. Затем `sum2(2, 7)` возвращает `9`. Снаружи к результату прибавляют `12`.

**Практика 2.6.2.** Напишите функцию `abs2(x)`, которая возвращает модуль числа без вызова встроенной `abs`. Проверьте на `5`, `-3` и `0`. Рядом напишите `max2(a, b)` и сравните её с встроенной `max` на парах `(2, 9)` и `(4, 4)`.

**Критерий 2.6.2:** первый `result` равен **7**, второй равен **21**. `abs2(-3)` равен `3`. `max2` совпадает с `max` на обеих парах.

## 2.6.3. Произвольное число параметров

`*args` собирает лишние позиционные аргументы в кортеж. Имя `args` обычное, звёздочка задаёт способ сборки.

**Ячейка:**

```python
def my_sum(*args):
    total = 0
    for item in args:
        total += item
    return total

print(my_sum(1, 2, 3, 4, 5))

numbers = (1, 2, 3, 4, 5)
print(my_sum(*numbers))
```

`my_sum(1, 2, 3, 4, 5)` передаёт пять аргументов. `my_sum(*numbers)` распаковывает кортеж в те же пять аргументов. Без звёздочки функция получила бы один аргумент — сам кортеж — и сложение со счётчиком упало бы с `TypeError`.

**Практика 2.6.3.** Вызовите `my_sum()` без аргументов и `my_sum(*[10, 20])`. Запишите оба результата.

**Критерий 2.6.3:** обе печати в ячейке дают **15**. Пустой вызов даёт `0`, вызов со списком через `*` даёт `30`.

## 2.6.4. Именованные параметры

Параметры после `*args` передают только по имени. У них может быть значение по умолчанию.

В стандартной библиотеке нет отдельной учебной функции среднего с заданной точностью. Её пишут так:

```python
def average(*args, accuracy=3):
    value = sum(args) / len(args)
    return round(value, accuracy)

numbers = (1, 2, 3, 4, 5)
print(average(*numbers))
print(average(*numbers, accuracy=1))
```

`average(*numbers)` считает среднее пяти чисел и округляет до трёх знаков: `3.0`. Второй вызов округляет до одного знака.

**Практика 2.6.4.** Вызовите `average(1, 2, 3)` и `average(1, 2, 3, accuracy=4)`. Убедитесь, что точность не попала в набор чисел.

**Критерий 2.6.4:** первое среднее — `3.0`, вызов с `accuracy=4` печатает `2.0` для `(1, 2, 3)`.

## 2.6.5. Позиционные аргументы не попадают в именованные

Добавьте второй именованный параметр и посмотрите, куда деваются числа без имени.

```python
def average(*args, accuracy=3, indent=10):
    value = sum(args) / len(args)
    text = str(round(value, accuracy))
    return text.rjust(indent, "*")

numbers = (1, 2, 3, 4, 5)
print(average(*numbers))
print(average(*numbers, indent=5, accuracy=4))
print(average(*numbers, 3, 10))
print(average(*numbers, 5, accuracy=4))
```

`average(*numbers, indent=5, accuracy=4)` передаёт точность и ширину по имени. Среднее `3.0` округляется до четырёх знаков и дополняется звёздочками до ширины 5.

`average(*numbers, 3, 10)` не записывает `3` в `accuracy`. Оба числа без имени попадают в `args`: последовательность становится `(1, 2, 3, 4, 5, 3, 10)`. Сумма `28`, длина `7`, среднее `4.0`. Поэтому печать — строка `4.0`, дополненная до ширины по умолчанию.

`average(*numbers, 5, accuracy=4)` добавляет `5` в числа. Среднее шести чисел — `3.3333` при точности 4.

Такой вызов — синтаксическая ошибка: позиционный аргумент стоит после именованного.

```python
average(*numbers, accuracy=5, 10)
```

**Практика 2.6.5.** Выполните ошибочную строку в отдельной ячейке, прочитайте `SyntaxError` и запишите в markdown, почему `10` нельзя поставить после `accuracy=5`. Затем вызовите `average(*numbers, accuracy=5, indent=10)` и сравните длину результата с `indent`.

**Критерий 2.6.5:** вызов с голыми `3, 10` даёт строку из `4.0` и звёздочек. Вызов с голой `5` и `accuracy=4` содержит `3.3333`. Правильный вызов только с именами не удлиняет набор чисел: в среднем участвуют пять исходных значений.

### Типовые ошибки

| Симптом | Что проверить |
|---------|----------------|
| После опыта с `print` ячейки молчат с `TypeError` | Имени `print` возвращена функция: `print = f` |
| `my_sum(numbers)` падает | Перед кортежем или списком нужна `*` |
| Точность округления стала ещё одним слагаемым | После `*args` параметры передают по имени: `accuracy=2` |
| `SyntaxError` на вызове `average` | Именованный аргумент стоит раньше позиционного |

После занятия слушатель описывает свою функцию, передаёт в неё последовательность через `*` и не путает числа последовательности с точностью и шириной строки.
