## 6.1.1. Наблюдение, признаки, цель

В таблице машинного обучения одна строка — одно наблюдение. Столбцы делятся на признаки, по которым делается вывод, и цель, которую нужно получить. Служебные поля в признаки не входят.

Задача занятий модуля: по часам практики и числу сданных работ оценить балл. Создайте `module-6-1/data/study.csv` в кодировке UTF-8:

```text
student_id,hours,works,group_code,score,score_note
1,2,1,A,40,балл 40
2,4,2,A,55,балл 55
3,6,2,B,70,балл 70
4,8,3,B,85,балл 85
5,3,1,A,48,балл 48
6,5,3,B,66,балл 66
7,7,3,A,78,балл 78
8,9,4,B,92,балл 92
```

| Столбец | Роль |
|---------|------|
| `hours`, `works` | Признаки |
| `score` | Цель |
| `student_id` | Номер строки, не свойство ученика для прогноза |
| `group_code` | Метка группы. На этом занятии в признаки не берём: разбор категорий — в занятии 6.3 |
| `score_note` | Текст, который уже содержит балл. Если оставить его среди признаков, модель увидит ответ |

**Ячейка:**

```python
import pandas as pd

raw = pd.read_csv("module-6-1/data/study.csv", encoding="utf-8")
print(raw.shape)
print(raw.dtypes)
print(raw.head(3))
```

**Критерий 6.1.1:** 8 строк и 6 столбцов. `hours`, `works` и `score` прочитаны как целые числа.

## 6.1.2. Матрица X и вектор y

Признаки собирают в таблицу `X`: столько строк, сколько наблюдений, и столько столбцов, сколько признаков. Цель — отдельный столбец `y` той же длины. Порядок строк в `X` и `y` один и тот же.

**Ячейка:**

```python
feature_columns = ["hours", "works"]
target_column = "score"

X = raw[feature_columns].copy()
y = raw[target_column].copy()

print("X", X.shape)
print("y", y.shape)
print(X.head(2))
print(y.head(2).tolist())
```

Проверка, что ответ не попал в признаки:

```python
forbidden = {"score", "score_note", "student_id"}
print("пересечение", sorted(set(X.columns) & forbidden))
```

**Практика 6.1.2.** В markdown напишите, почему `score_note` нельзя ставить в `feature_columns`, даже если убрать сам столбец `score`.

**Критерий 6.1.2:** `X` имеет форму `(8, 2)`, `y` — длину 8, пересечение с запрещёнными именами пустое. Сумма `hours` равна **44**, сумма `y` равна **534**.

## 6.1.3. Обучение и проверка

Часть строк оставляют для обучения, часть — для проверки. Проверочные строки не участвуют в настройке модели, поэтому по ним позже видно, как она ведёт себя на новых наблюдениях. Разбиение делает `train_test_split`.

**Ячейка:**

```python
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
print(X_train.shape, X_test.shape)
print(y_train.shape, y_test.shape)
print("те же столбцы", list(X_train.columns) == list(X_test.columns))
```

`test_size=0.25` при 8 строках отдаёт 2 строки в проверку и 6 в обучение. `random_state=42` фиксирует, какие именно строки попадут в проверку: повторный запуск даёт то же разбиение.

Индексы исходной таблицы сохраняются. По ним видно, что пара «признаки — цель» не перепуталась:

```python
print(X_test)
print(y_test.loc[X_test.index].tolist())
```

**Критерий 6.1.3:** формы `(6, 2)` и `(2, 2)`. Столбцы обучения и проверки совпадают. Сумма `y_train` и `y_test` равна **534**.

## 6.1.4. Одна новая строка

Модель потом получает не всю исходную таблицу, а строку только из признаков, в том же порядке столбцов.

**Ячейка:**

```python
new_row = pd.DataFrame([{"hours": 5, "works": 2}])
new_row = new_row[feature_columns]
print(new_row)
print("столбцы как у X", list(new_row.columns) == feature_columns)
print("форма", new_row.shape)
```

Форма `(1, 2)`: одно наблюдение и оба признака. Список из двух чисел без имён столбцов для этой проверки не используйте: по позиции легко поменять часы и число работ местами.

**Практика 6.1.4.** Соберите вторую строку с `hours=1`, `works=4` и посмотрите, что получится, если взять столбцы в порядке `["works", "hours"]`. В markdown напишите, чем эта таблица опасна при сравнении с `X_train`.

**Критерий 6.1.4:** у строки в порядке `feature_columns` сначала `hours`, затем `works`, форма `(1, 2)`.

## 6.1.5. Сохранение частей

Четыре части записывают отдельно. Так следующее занятие может прочитать готовые входы, не повторяя разбор исходного файла.

```python
from pathlib import Path

folder = Path("module-6-1/data")
X_train.to_csv(folder / "X_train.csv", index=False, encoding="utf-8")
X_test.to_csv(folder / "X_test.csv", index=False, encoding="utf-8")
y_train.to_csv(folder / "y_train.csv", index=False, encoding="utf-8")
y_test.to_csv(folder / "y_test.csv", index=False, encoding="utf-8")

X_train_check = pd.read_csv(folder / "X_train.csv", encoding="utf-8")
y_train_check = pd.read_csv(folder / "y_train.csv", encoding="utf-8")
print(X_train_check.shape, y_train_check.shape)
print(X_train_check.columns.tolist())
print("сумма цели", int(y_train_check["score"].sum() + pd.read_csv(folder / "y_test.csv")["score"].sum()))
```

**Критерий 6.1.5:** `X_train.csv` содержит столбцы `hours` и `works` и 6 строк. Сумма `score` в двух файлах цели снова **534**.

### Типовые ошибки

| Симптом | Что проверить |
|---------|----------------|
| `y` оказался таблицей из одного столбца, а ожидали столбец значений | Для одного целевого столбца берите `raw["score"]`, не список из одного имени внутри двойных скобок, если дальше нужен Series |
| В проверку попало 8 строк или 0 | `test_size=0.25` и данные из 8 строк |
| Другие две строки в `X_test`, чем у соседнего слушателя | Должен быть `random_state=42` |
| Сумма баллов обучения и проверки не 534 | Строка попала в обе части или цель взята не из `score` |
| Новая строка с переставленными часами и работами | Перед прогнозом нужен порядок `feature_columns` |
| `FileNotFoundError` | Пути `module-6-1/data/...` от корня курса |

После занятия слушатель отделяет признаки от цели, не кладёт в `X` ответ и номер строки и сохраняет обучение и проверку с одинаковым списком столбцов.
