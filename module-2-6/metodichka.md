# 2.6. Отладка

**Объём занятия:** 2 академических часа (~120 минут) активной практики в Visual Studio Code.

**Цель:** останавливать программу в нужной строке, смотреть переменные и находить ошибку шагами отладчика, а не догадкой по `print`.

**Опора:** расширение **Python** и интерпретатор `./.venv/Scripts/python.exe`. Рабочая папка VS Code — корень курса.

**Итоговые артефакты** (в папке `module-2-6/`):

| Файл | Назначение |
|------|------------|
| `debug_demo.py` | Скрипт, на котором ставят точки останова |
| `bug_average.py` | Скрипт с ошибкой, которую находят отладчиком |
| `lab26-debug.md` | Короткая заметка: что было в переменных на остановке |

---

## Подготовка

Проверьте интерпретатор: `Ctrl+Shift+P` → **Python: Select Interpreter** → `./.venv/Scripts/python.exe`. Отладчик запускает тот интерпретатор, который выбран в статусной строке.

---

## 2.6.1. Точка останова

Создайте `module-2-6/debug_demo.py`:

```python
def grade(score: int) -> str:
    if score >= 18:
        label = "зачёт с отличием"
    elif score >= 12:
        label = "зачёт"
    else:
        label = "нужна доработка"
    return label


def main():
    scores = [18, 15, 9]
    for score in scores:
        result = grade(score)
        print(score, result)


if __name__ == "__main__":
    main()
```

1. Щёлкните слева от номера строки `result = grade(score)`. Появится красная точка.
2. Откройте **Run and Debug** (`Ctrl+Shift+D`) и запустите **Python File**.
3. Выполнение остановится до этой строки. В панели **Variables** найдите `score`.
4. **Continue** (`F5`) переходит к следующей остановке. Пройдите все три числа.

**Практика 2.6.1.** В `lab26-debug.md` запишите три значения `score`, которые видели на остановке, и три строки из отладочной консоли.

**Критерий 2.6.1:** остановка срабатывает три раза, в консоли есть пары `18 зачёт с отличием`, `15 зачёт`, `9 нужна доработка`.

---

## 2.6.2. Шаг внутрь и шаг через

На строке вызова `grade(score)` доступны два шага:

| Клавиша | Команда | Куда переходит |
|---------|---------|----------------|
| `F10` | Step Over | Выполняет вызов целиком и остаётся в `main` |
| `F11` | Step Into | Входит в первую строку `grade` |
| `Shift+F11` | Step Out | Выполняет функцию до `return` и возвращается к вызывающему коду |

**Практика 2.6.2.** Поставьте точку на строке вызова. Нажмите `F11`. Внутри `grade` дойдите до присваивания `label` клавишей `F10`. Для балла `9` в **Variables** должно появиться `label` со значением «нужна доработка». Затем `Shift+F11` вернёт вас в цикл.

**Критерий 2.6.2:** в заметке записано, что при `score == 9` переменная `label` равна «нужна доработка» ещё до выхода из функции.

## 2.6.3. Условная точка останова

Останавливаться на каждом элементе неудобно, если ошибка только в одном значении. Правый щелчок по красной точке → **Edit Breakpoint** → выражение `score < 12`.

Запустите отладку снова. Остановка будет только для `9`. Значения 18 и 15 выполнятся без паузы.

**Практика 2.6.3.** Смените условие на `score == 15`, запустите ещё раз и убедитесь, что пауза одна и в переменной именно 15. После проверки условие можно снять.

**Критерий 2.6.3:** при условии `score < 12` отладчик останавливается один раз.

## 2.6.4. Поиск ошибки

Создайте `module-2-6/bug_average.py`. Среднее считается неверно: сумма делится не на число элементов.

```python
def average(values: list[int]) -> float:
    total = 0
    for value in values:
        total += value
    return total / (len(values) - 1)


def main():
    scores = [18, 15, 20, 11]
    print("среднее:", average(scores))


if __name__ == "__main__":
    main()
```

Верное среднее — `(18 + 15 + 20 + 11) / 4 = 16`. Скрипт печатает другое число.

1. Поставьте точку останова на строке `return`.
2. Запустите отладчик.
3. В **Watch** добавьте выражения `total`, `len(values)` и `len(values) - 1`.
4. Сравните делитель с числом оценок.

**Практика 2.6.4.** Исправьте делитель на `len(values)`. Запустите файл обычным образом, без отладчика:

```powershell
python module-2-6\bug_average.py
```

**Критерий 2.6.4:** до исправления в Watch видно деление на 3 при четырёх оценках. После исправления скрипт печатает `среднее: 16.0`.

## 2.6.5. Отладочная консоль

Пока программа стоит на точке останова, панель **Debug Console** выполняет выражения в этом месте. Это не терминал: команды `cd` здесь не работают.

На остановке внутри `average` наберите:

```python
values
total / len(values)
```

Второе выражение показывает среднее, не меняя файл. Так проверяют догадку до правки кода.

**Критерий 2.6.5:** консоль на остановке печатает список из четырёх баллов и число `16.0`.

### Типовые ошибки

| Симптом | Что проверить |
|---------|----------------|
| Отладчик использует не `.venv` | Статусная строка и **Python: Select Interpreter** |
| Точка серая и не срабатывает | Файл сохранён, запущена именно эта копия, строка выполняется |
| `F10` не входит в `grade` | Для входа нужна `F11` |
| В Watch ошибка имени | Имя есть только внутри функции; смотрите его на остановке внутри неё |
| После правки всё ещё старый результат | Остановлен предыдущий сеанс: кнопка Stop, затем новый запуск |

После занятия слушатель останавливает цикл на нужном значении, читает локальные переменные и проверяет исправление повторным запуском.
