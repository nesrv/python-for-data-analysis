## 6.0.1. Как модель получает ответ

Модель учится на уже известных парах «признаки — цена». Дерево решений делит квартиры по порогу одного признака. В каждом листе прогноз — среднее цен квартир, которые в этот лист попали.

В этой таблице порог по площади виден без библиотеки. Квартиры до 60 м² включительно — одна группа, квартиры просторнее — другая.

**Ячейка:**

```python
import pandas as pd

raw = pd.read_csv("module-6-0/data/flats.csv", encoding="utf-8")
print(raw.shape)
print(raw.head(3))

left = raw.loc[raw["area"] <= 60, "price"]
right = raw.loc[raw["area"] > 60, "price"]
print("среднее до 60 м2", left.mean())
print("среднее больше 60 м2", right.mean())

pred_rule = raw["area"].apply(lambda area: left.mean() if area <= 60 else right.mean())
mae_rule = (raw["price"] - pred_rule).abs().mean()
print("ошибка правила", round(mae_rule))
```

Шесть небольших квартир дают среднее **5000**. Шесть больших — **9000**. Правило «маленькая → 5000, большая → 9000» ошибается в среднем на **533** тысячи рублей. Это ручная проверка порога. В разделе 6.0.3 дерево само выбирает пороги и может делить лист повторно.

**Критерий 6.0.1:** в файле 12 строк и 7 столбцов. Средние групп — 5000 и 9000. Округлённая ошибка правила — 533.

## 6.0.3. Первая модель

Признаки собирают в `X`, цель — в `y`. `DecisionTreeRegressor` строит дерево: `fit` подбирает разбиения по известным ценам, `predict` выдаёт цену для переданных строк.

**Ячейка:**

```python
from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_absolute_error

features = ["area", "year", "rooms"]
X = raw[features].copy()
y = raw["price"].copy()

model = DecisionTreeRegressor(random_state=1)
model.fit(X, y)
pred_train = model.predict(X)

print(X.shape, y.shape, pred_train.shape)
print(pred_train[:3])
print("ошибка на тех же строках", mean_absolute_error(y, pred_train))
```

`random_state=1` фиксирует выбор, если алгоритму всё равно, какой признак взять. Ошибка на тех же строках, на которых дерево училось, равна **0**: у каждой квартиры свой набор `area`, `year`, `rooms`, и дерево доводит лист до одной квартиры. Такая ошибка показывает, что дерево запомнило таблицу. Про новые квартиры она ничего не говорит.

**Критерий 6.0.3:** `X` имеет форму `(12, 3)`, прогноз — длину 12, средняя абсолютная ошибка на этих 12 строках равна 0.

## 6.0.4. Проверка на отложенных строках

Часть квартир откладывают до `fit`. Дерево их не видит, и ошибка на них ближе к ошибке на новой квартире. Деление делает `train_test_split`. Метрика занятия — средняя абсолютная ошибка, MAE: среднее модуля «прогноз минус факт».

**Ячейка:**

```python
from sklearn.model_selection import train_test_split

train_X, val_X, train_y, val_y = train_test_split(X, y, random_state=1)
print(train_X.shape, val_X.shape)

val_model = DecisionTreeRegressor(random_state=1)
val_model.fit(train_X, train_y)
val_pred = val_model.predict(val_X)

mae_train = mean_absolute_error(train_y, val_model.predict(train_X))
mae_val = mean_absolute_error(val_y, val_pred)
print("MAE обучение", mae_train)
print("MAE проверка", mae_val)
```

При 12 строках и доле проверки по умолчанию 0,25 в обучении 9 квартир, в проверке 3. `random_state=1` оставляет тот же состав групп при повторном запуске.

**Практика 6.0.4.** В markdown запишите оба числа MAE и ответьте, какое из них вы покажете заказчику как оценку качества.

**Критерий 6.0.4:** формы `(9, 3)` и `(3, 3)`. MAE на обучении равна 0. MAE на проверке больше 0.

## 6.0.5. Число листьев

Мало листьев — дерево делит квартиры слишком грубо, прогнозы в листе усредняют непохожие цены. Много листьев — дерево подстраивается под каждую учебную квартиру, и на отложенных строках ошибка снова растёт. Размер ограничивают параметром `max_leaf_nodes`.

Сравнивают несколько значений на одной и той же проверке.

**Ячейка:**

```python
def mae_for_leaves(max_leaf_nodes):
    tree = DecisionTreeRegressor(max_leaf_nodes=max_leaf_nodes, random_state=1)
    tree.fit(train_X, train_y)
    return mean_absolute_error(val_y, tree.predict(val_X))

candidates = [2, 4, 6, 8]
scores = {leaves: mae_for_leaves(leaves) for leaves in candidates}
for leaves, score in scores.items():
    print(leaves, round(score, 1))

best_leaves = min(scores, key=scores.get)
print("листьев", best_leaves, "MAE", round(scores[best_leaves], 1))
```

**Практика 6.0.5.** В markdown выпишите четыре MAE и число листьев с наименьшей ошибкой на проверке. Рядом одной фразой опишите, что делает с прогнозом дерево из двух листьев.

**Критерий 6.0.5:** для каждого значения из списка `2, 4, 6, 8` напечатана ошибка на `val_y`. Выбранное число листьев — то, у которого эта ошибка минимальна.

## 6.0.6. Случайный лес

Случайный лес строит много деревьев. Каждое видит свою выборку строк и свой набор признаков в разбиениях. Прогноз леса — среднее прогнозов деревьев. Одно неудачное дерево меньше сдвигает ответ.

**Ячейка:**

```python
from sklearn.ensemble import RandomForestRegressor

forest = RandomForestRegressor(random_state=1)
forest.fit(train_X, train_y)
forest_mae = mean_absolute_error(val_y, forest.predict(val_X))
print("MAE лес", round(forest_mae, 1))
print("MAE лучшее дерево", round(scores[best_leaves], 1))
print("число деревьев", forest.n_estimators)
```

Лес учат на `train_X` и `train_y`. Проверочные три квартиры в `fit` не передают.

**Практика 6.0.6.** В markdown запишите, какая MAE меньше: у леса или у дерева с `best_leaves`.

**Критерий 6.0.6:** напечатаны обе ошибки на `val_y`. `forest.n_estimators` больше 1.

## 6.0.7. Прогноз для новых квартир

Новая квартира приходит без цены и без текста `price_note`. Столбцы и их порядок те же, что у `X`. Файл с прогнозом — две колонки: номер и цена. Его сохраняют локально.

**Ячейка:**

```python
from pathlib import Path

new_flats = pd.DataFrame(
    [
        {"flat_id": 101, "area": 45, "year": 1988, "rooms": 2},
        {"flat_id": 102, "area": 88, "year": 2015, "rooms": 3},
    ]
)
new_X = new_flats[features]
new_price = forest.predict(new_X)

submission = pd.DataFrame(
    {"flat_id": new_flats["flat_id"], "price": new_price.round(1)}
)
out = Path("module-6-0/data/new_prices.csv")
submission.to_csv(out, index=False, encoding="utf-8")
print(submission)
print("столбцы как у X", list(new_X.columns) == features)
```

Квартира 101 ближе к группе до 60 м², квартира 102 — к группе просторных. Прогноз леса складывается из площади, года и числа комнат.

**Критерий 6.0.7:** в `new_prices.csv` две строки, столбцы `flat_id` и `price`, номера 101 и 102. В `new_X` нет `price` и `price_note`.

### Типовые ошибки

| Симптом | Что проверить |
|---------|----------------|
| Ошибка на всех 12 строках больше 0 | В `X` попали одинаковые комбинации признаков или стоит `max_leaf_nodes` |
| В проверке не 3 строки | `train_test_split(X, y, random_state=1)` без другого `test_size` |
| MAE проверки равна 0 | В `fit` ушли все 12 строк, а не `train_X` |
| У всех чисел листьев одна и та же ошибка | В `DecisionTreeRegressor` не передан `max_leaf_nodes` |
| Лес видел проверочные цены | `fit` вызывают от `train_X, train_y` |
| В прогнозе для 101 и 102 есть столбец `price_note` | В `new_X` список `features` |
| `FileNotFoundError` | Путь `module-6-0/data/flats.csv` от корня курса |
