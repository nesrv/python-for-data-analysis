7. Пропуски, категории, проверка и бустинг

Продолжение занятия 6.0. Семь коротких страниц: от повторения слов до утечки, которая незаметно завышает точность. Данные лежат в module-7-0/data/: квартиры с пустыми ячейками и заявки на карту.

  1. Введение (Introduction)
    Повторите всё необходимое для прохождения этого блока.
  2. Пропущенные значения (Missing Values)
    Пропущенные значения — распространённая проблема. Будьте готовы встретить её в реальных наборах данных.
  3. Категориальные переменные (Categorical Variables)
    В данных много нечисловой информации. Узнайте, как использовать её в машинном обучении.
  4. Конвейеры обработки данных (Pipelines)
    Важный навык для развёртывания и тестирования сложных моделей с предварительной обработкой данных.
  5. Кросс-валидация (Cross-Validation)
    Более устойчивый способ проверки качества ваших моделей.
  6. XGBoost
    Один из наиболее точных методов машинного обучения для структурированных данных.
  7. Утечка данных (Data Leakage)
    Научитесь находить и устранять эту проблему, которая может незаметно испортить результаты модели.
  8. Практическое занятие. Честная цена
    4 академических часа: подпись цены, простое правило, лес, складки и прогноз для трёх новых квартир.
