Опора: ход занятия — как устроена модель, разведка таблицы, первая модель, проверка, недообучение и переобучение, случайный лес, прогноз для новых строк. Берут файл цен квартир города М. 6.0.1. Как модель получает ответ

Модель учится на уже известных парах «признаки — цена». Дерево решений задаёт вопрос к одному признаку и делит строки на две кучки. В листе — квартирах, которые дошли до конца ветки, — прогноз равен средней их цене.

Пока библиотека не нужна: порог по площади виден руками. Квартиры до 60 м² включительно — одна группа, квартиры просторнее — другая. Если правило осмысленно, средние двух групп разойдутся, а средняя ошибка будет меньше, чем если всем предсказывать одно и то же число.

Ячейка:

import pandas as pd

# Таблица из файла. encoding нужен, чтобы русские буквы в районе не превратились в кракозябры.
raw = pd.read_csv("module-6-0/data/flats.csv", encoding="utf-8")
print(raw.shape)   # (число строк, число столбцов)
print(raw.head(3)) # три первые квартиры, чтобы увидеть имена столбцов

# Две группы по одному порогу. loc оставляет только нужные строки, "price" — только столбец цели.
left = raw.loc[raw["area"] <= 60, "price"]
right = raw.loc[raw["area"] > 60, "price"]
print("среднее до 60 м2", left.mean())
print("среднее больше 60 м2", right.mean())

# Для каждой квартиры подставляем среднее её группы. Это и есть прогноз правила.
pred_rule = raw["area"].apply(lambda area: left.mean() if area <= 60 else right.mean())
# Модуль разности — промах в тысячах рублей. mean усредняет промахи по всем строкам файла.
mae_rule = (raw["price"] - pred_rule).abs().mean()
print("ошибка правила", round(mae_rule))

Квартир до 60 м² включительно — 3563, их средняя цена 4418.95. Квартир просторнее — 6437, средняя 8026.64. Правило «не больше 60 м² → 4418.95, иначе → 8026.64» ошибается в среднем на 1029 тысяч рублей. Порог 60 выбран глазами. В разделе 6.0.3 дерево само перебирает пороги и может разрезать группу ещё раз.

Критерий 6.0.1: в файле 10000 строк и 7 столбцов. Средние групп, если оставить два знака, — 4418.95 и 8026.64. Округлённая ошибка правила — 1029.

6.0.2. Разведка таблицы

Перед обучением смотрят размер, типы, пропуски и сводку по числам. Иначе легко отдать модели столбец, в котором цена уже написана словами, или строку без цены: такую строку не на чем учить и не с чем сравнивать прогноз.

Столбец Роль
area, year, rooms Признаки: их модель имеет право видеть
price Цель, тысячи рублей. В признаки её не кладут
flat_id Номер квартиры. На цену сам по себе не влияет
district Район текстом. В первой модели его нет: текст надо сначала превратить в числа
price_note Текст, в котором уже записана цена. Если отдать его модели, она прочитает ответ

Ячейка:

print(raw.dtypes)  # int, float или текст. Модель из этого занятия ест только числа
# isna помечает пустые ячейки. Сумма по всей таблице — сколько пустых ячеек всего.
print("пропуски", int(raw.isna().sum().sum()))
# describe: количество, среднее, минимум, максимум. Так видно размах площади и цены.
print(raw[["area", "year", "rooms", "price"]].describe())
print("средняя цена", raw["price"].mean())
print("сумма цен", int(raw["price"].sum()))
print("сумма площадей", int(raw["area"].sum()))

У части квартир в реальной выгрузке нет цены продажи. Такие строки убирают: без цели строку не на чем учить. В flats.csv пустых ячеек нет, сумма пропусков равна 0. Средняя цена по всем 10000 квартирам — 6741.2226.

6.0.3. Первая модель

Признаки собирают в таблицу X, цель — в столбец y. Строка X и число y с тем же номером — одна квартира. DecisionTreeRegressor строит дерево: fit подбирает вопросы по известным ценам, predict отвечает ценой для переданных строк.

Ячейка:

from sklearn.tree import DecisionTreeRegressor
from sklearn.metrics import mean_absolute_error

features = ["area", "year", "rooms"]  # только эти три столбца увидит дерево
X = raw[features].copy()  # копия, чтобы случайная правка X не меняла исходный raw
y = raw["price"].copy()   # известные цены, по ним дерево учится

# random_state фиксирует выбор, если два признака дают одинаково хорошее разбиение.
model = DecisionTreeRegressor(random_state=1)
model.fit(X, y)             # обучение: подобрать пороги
pred_train = model.predict(X)  # прогноз для тех же 10000 квартир

print(X.shape, y.shape, pred_train.shape)
print(pred_train[:3])  # три первых прогноза, чтобы увидеть числа, а не только ошибку
print("ошибка на тех же строках", mean_absolute_error(y, pred_train))

Ошибка на тех же строках, на которых дерево училось, равна 0. У каждой квартиры свой набор area, year, rooms, и без ограничения на число листьев дерево доводит ветку до одной квартиры: в листе среднее из одного числа совпадает с фактом. Ноль здесь значит «таблица запомнена», а не «новые квартиры будут угаданы».

Критерий 6.0.3: X имеет форму (10000, 3), прогноз — длину 10000, средняя абсолютная ошибка на этих 10000 строках равна 0.

6.0.4. Проверка на отложенных строках

Часть квартир откладывают и не показывают методу fit. Дерево подбирает пороги только по остальным. Ошибка на спрятанных строках ближе к ошибке на квартире, которой в файле не было. Деление делает train_test_split. Метрика занятия — MAE: среднее модуля «прогноз минус факт». Меньше — ближе к настоящей цене.

Ячейка:

from sklearn.model_selection import train_test_split

# Четыре части: признаки и цены для обучения, признаки и цены для проверки.
# Порядок один и тот же: строка train_X[i] относится к цене train_y[i].
train_X, val_X, train_y, val_y = train_test_split(X, y, random_state=1)
print(train_X.shape, val_X.shape)

val_model = DecisionTreeRegressor(random_state=1)
val_model.fit(train_X, train_y)      # цены val_y сюда не передают
val_pred = val_model.predict(val_X)  # прогноз для спрятанных квартир

mae_train = mean_absolute_error(train_y, val_model.predict(train_X))
mae_val = mean_absolute_error(val_y, val_pred)
print("MAE обучение", mae_train)
print("MAE проверка", mae_val)

При 10000 строках и доле проверки по умолчанию 0,25 в обучении 7500 квартир, в проверке 2500. random_state=1 каждый раз оставляет тот же состав групп, иначе повторный запуск ячейки даст другие квартиры и другое число.

Заказчику показывают MAE проверки. MAE обучения при неограниченном дереве снова 0 и про новую квартиру молчит.

Практика 6.0.4. В markdown запишите оба числа MAE и одной фразой объясните, почему заказчику нельзя показывать нулевую ошибку обучения.

Критерий 6.0.4: формы (7500, 3) и (2500, 3). MAE на обучении равна 0. MAE на проверке больше 0.

6.0.5. Число листьев

Лист — конец ветки, там живёт один прогноз. Мало листьев — в одном листе сидят непохожие квартиры, и среднее смазывает цену. Много листьев — дерево выделяет лист почти каждой учебной квартире и на спрятанных строках снова промахивается. Это и есть грубое дерево против запомненной таблицы.

Размер ограничивают параметром max_leaf_nodes. Сравнивают несколько значений на одной и той же проверке: состав train и val не меняют, меняется только потолок листьев.

Ячейка:

def mae_for_leaves(max_leaf_nodes):
    # Каждое дерево учится на тех же 7500 квартирах и проверяется на тех же 2500.
    tree = DecisionTreeRegressor(max_leaf_nodes=max_leaf_nodes, random_state=1)
    tree.fit(train_X, train_y)
    return mean_absolute_error(val_y, tree.predict(val_X))

candidates = [2, 4, 6, 8]
# Словарь: ключ — сколько листьев разрешили, значение — MAE на проверке.
scores = {leaves: mae_for_leaves(leaves) for leaves in candidates}
for leaves, score in scores.items():
    print(leaves, round(score, 1))

# min с key выбирает ключ с наименьшим значением, а не само значение.
best_leaves = min(scores, key=scores.get)
print("листьев", best_leaves, "MAE", round(scores[best_leaves], 1))

Дерево из двух листьев делает по сути один разрез и два средних — как ручное правило из раздела 6.0.1, только порог выбирает само.

Практика 6.0.5. В markdown выпишите четыре MAE и число листьев с наименьшей ошибкой на проверке. Рядом одной фразой опишите, что делает с прогнозом дерево из двух листьев.

Критерий 6.0.5: для каждого значения из списка 2, 4, 6, 8 напечатана ошибка на val_y. Выбранное число листьев — то, у которого эта ошибка минимальна.

6.0.6. Случайный лес

Одно дерево на 2500 проверочных квартирах легко попадает в неудачный порог. Случайный лес строит много деревьев. Каждое видит не все учебные строки и не все признаки в каждом вопросе. Итоговая цена — среднее ответов деревьев: один странный прогноз разбавляется остальными.

Ячейка:

from sklearn.ensemble import RandomForestRegressor

forest = RandomForestRegressor(random_state=1)
forest.fit(train_X, train_y)  # снова только учебные 7500 квартир
forest_mae = mean_absolute_error(val_y, forest.predict(val_X))
print("MAE лес", round(forest_mae, 1))
print("MAE лучшее дерево", round(scores[best_leaves], 1))
print("число деревьев", forest.n_estimators)  # сколько деревьев усредняется

Лес и лучшее дерево сравнивают на одних и тех же 2500 квартирах. Меньшая MAE — более устойчивый прогноз на этой проверке, не гарантия на любую новую квартиру города М.

Практика 6.0.6. В markdown запишите, какая MAE меньше: у леса или у дерева с best_leaves.

Критерий 6.0.6: напечатаны обе ошибки на val_y. forest.n_estimators больше 1.

6.0.7. Прогноз для новых квартир

Новая квартира приходит без цены и без текста price_note. Столбцы и их порядок те же, что у X: модель помнит, что первый столбец — площадь, второй — год, третий — комнаты. Файл с прогнозом — две колонки: номер и цена. Его сохраняют локально.

Ячейка:

from pathlib import Path

# Две квартиры, которых не было в flats.csv. Цены у них нет — её как раз и просим.
new_flats = pd.DataFrame(
    [
        {"flat_id": 10001, "area": 45, "year": 1988, "rooms": 2},
        {"flat_id": 10002, "area": 88, "year": 2015, "rooms": 3},
    ]
)
new_X = new_flats[features]          # тот же список столбцов, что при обучении
new_price = forest.predict(new_X)    # лес, уже обученный на train_X

submission = pd.DataFrame(
    {"flat_id": new_flats["flat_id"], "price": new_price.round(1)}
)
out = Path("module-6-0/data/new_prices.csv")
submission.to_csv(out, index=False, encoding="utf-8")  # index=False не пишет 0 и 1 в файл
print(submission)
print("столбцы как у X", list(new_X.columns) == features)

Квартира 10001 ближе к группе до 60 м², квартира 10002 — к группе просторных. Номера стоят после 10000, поэтому этих строк в flats.csv нет. Прогноз леса складывается из площади, года и числа комнат, а не из одного порога 60.

Критерий 6.0.7: в new_prices.csv две строки, столбцы flat_id и price, номера 10001 и 10002. В new_X нет price и price_note.
