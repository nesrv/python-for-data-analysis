2.1.1. Изменяемые и неизменяемые типы

Неизменяемый объект нельзя поменять «на месте»: операция создаёт новое значение. Изменяемый объект можно дополнить или перезаписать, и все имена, которые на него ссылаются, увидят это изменение.

Неизменяемые: int, float, bool, str, tuple, frozenset, None.

Изменяемые: list, dict, set и большинство объектов своих классов.

Ячейка — неизменяемое число и строка:

n = 10
print("id до", id(n))
n = n + 1
print("n =", n, "id после", id(n))

s = "py"
print("строка до", id(s))
s = s + "thon"
print("строка", s, "id после", id(s))

Имя n после сложения указывает на другой объект. Исходное число 10 не изменилось.

Ячейка — изменяемый список:

items = ["a"]
print("id списка", id(items))
items.append("b")
items[0] = "A"
print(items, "id тот же", id(items))

append и запись по индексу меняют тот же список: id не меняется.

Ячейка — кортеж с изменяемым элементом:

pair = (1, ["x"])
# pair[0] = 2          # TypeError: кортеж неизменяем
pair[1].append("y")    # список внутри кортежа изменяем
print(pair)

Неизменяемость кортежа запрещает заменить элемент. Она не замораживает объекты, которые уже лежат внутри.

Ячейка — что можно использовать как ключ:

catalog = {("Анна", 1): 18, "Борис": 15}
print(catalog[("Анна", 1)])
# catalog[["Вера"]] = 20  # TypeError: список нельзя сделать ключом

Ключ словаря должен быть неизменяемым.

Практика 2.1.1. Для каждого значения запишите в markdown «изменяемое» или «неизменяемое»: 3.14, "текст", [1, 2], (1, 2), {"a": 1}, {1, 2}, True.

Критерий 2.1.1: у числа и строки id после переприсваивания другой; у списка после append id тот же; кортеж с вложенным списком печатает (1, ['x', 'y']); практика заполнена.

2.1.2. Что такое объект

У любого значения есть тип (type), содержимое и идентичность (id). Имя в программе — ссылка на объект, а не «коробка с копией».

Ячейка A1:

x = 1000
y = x
print(type(x), type(x).__name__)
print("id x", id(x), "id y", id(y), "один объект", x is y)
y = 1001
print("после нового числа:", x, y, x is y)

Ячейка A2 — атрибуты и методы:

text = "Data"
print(text.upper())
print("методы-кандидаты:", [name for name in dir(text) if not name.startswith("_")][:8])

Ячейка A3 — isinstance:

samples = [1, 1.0, "1", True, None]
for item in samples:
    print(repr(item),
          "int", isinstance(item, int),
          "str", isinstance(item, str))

Критерий 2.1.2: после y = 1001 имена x и y ссылаются на разные объекты (x is y — ложь). В выводе True имеет тип bool, и isinstance(True, int) истинен: bool — подтип int. Зафиксируйте это одной фразой в markdown.

Ячейка B1 — числа:

print(7 + 3, 7 - 3, 7 * 3, 7 / 3, 7 // 3, 7 % 3, 2 ** 10)

2.1.4. Списки и кортежи

Ячейка C1 — список изменяем, имя — ссылка:

nums = [1, 2, 3]
alias = nums
alias.append(4)
print("nums", nums, "alias is nums", alias is nums)

copy = nums.copy()
copy.append(5)
print("после copy:", nums, copy, copy is nums)

Ячейка C2 — типовые операции:

scores = [15, 18, 9, 20, 12]
print(len(scores), min(scores), max(scores), sum(scores))
print(sorted(scores))
print("исходный порядок сохранён:", scores)
scores.sort()
print("после sort:", scores)

sorted возвращает новый список. list.sort меняет объект на месте и возвращает None.

Ячейка C3 — кортеж:

point = (10, 20)
x, y = point
print(x, y, type(point))
# point[0] = 0  # TypeError
one = (7,)
print(type(one), type((7)))

Скобки вокруг одного числа не делают кортеж. Кортеж из одного элемента пишется с запятой: (7,).

Ячейка C4 — вложенность:

table = [[1, 2], [3, 4]]
table[0].append(9)
print(table)

Практика 2.1.4. Соберите из scores новый список только значений >= 12 (цикл или списковое включение) и посчитайте их среднее.

Критерий 2.1.4: append через alias меняет nums; copy — нет. Среднее отобранных баллов посчитано в выводе ячейки.

2.1.5. Словари и множества

Ячейка D1 — словарь:

student = {"name": "Анна", "score": 18}
student["group"] = "A"
print(student["name"], student.get("city", "не указан"))
for key, value in student.items():
    print(key, "->", value)

Ключ должен быть неизменяемым (str, int, tuple). Список ключом быть не может.

Ячейка D2 — множество:

visited = {"Анна", "Борис", "Анна"}
print(visited, len(visited))
visited.add("Вера")
print("Борис" in visited)
print(visited & {"Борис", "Глеб"})

Порядок элементов множества не гарантирован, повторы исчезают.

Практика 2.1.5. Дан список имён с повторами: ["Анна", "Борис", "Анна", "Вера", "Борис"]. Получите число уникальных имён и словарь «имя → сколько раз встретилось».

Критерий 2.1.5: уникальных имён 3; у «Анна» и «Борис» счётчик 2, у «Вера» — 1.

2.1.6. Свой тип: класс

Объекты пользовательского класса устроены так же: экземпляр, тип, атрибуты, методы.

Файл module-2-1/objects_demo.py:

class Score:
    def __init__(self, name: str, points: int):
        self.name = name
        self.points = points

    def passed(self) -> bool:
        return self.points >= 12

    def __repr__(self) -> str:
        return f"Score({self.name!r}, {self.points})"


def main():
    group = [Score("Анна", 18), Score("Борис", 9), Score("Вера", 12)]
    print(type(group[0]).__name__)
    print(isinstance(group[0], Score))
    passed = [item for item in group if item.passed()]
    print(passed)


if __name__ == "__main__":
    main()

Запуск из корня проекта:

python module-2-1\objects_demo.py

В ноутбуке — ячейка с тем же классом и списком из трёх объектов (можно скопировать класс). Выведите только тех, у кого passed() истинно.

Критерий 2.1.6: в консоли тип Score, isinstance истинен, в списке сдавших нет Бориса.
