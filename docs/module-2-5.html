2.5 Управление потоком выполнение и ветвление

Цель: выбирать ветку if / elif / else, записывать короткий выбор тернарным оператором и сопоставлением match, присваивать значение по ходу выражения моржовым оператором :=, повторять действия циклом for и while и управлять циклом через break и continue.

Опора: ноутбук в VS Code, ядро — ./.venv/Scripts/python.exe. Рабочая папка — корень курса.

Итоговый артефакт: module-2-5/lab25-flow.ipynb со всеми ячейками и сохранённым выводом.

Подготовка

Создайте ноутбук module-2-5/lab25-flow.ipynb и выберите ядро .venv. Первая ячейка — markdown: ФИО, дата, заголовок «2.5 Управление потоком выполнение и ветвление».

Данные для примеров задайте в первой ячейке кода и больше не меняйте:

students = [
    {"name": "Анна", "score": 18},
    {"name": "Борис", "score": 15},
    {"name": "Вера", "score": 20},
    {"name": "Глеб", "score": 11},
]

2.5.1. Ветвление

Условие проверяется сверху вниз. Выполняется первая истинная ветка, остальные пропускаются.

Ячейка:

def grade(score: int) -> str:
    if score >= 18:
        return "зачёт с отличием"
    elif score >= 12:
        return "зачёт"
    else:
        return "нужна доработка"

for row in students:
    print(row["name"], row["score"], "->", grade(row["score"]))

Порядок условий важен. Если первым поставить score >= 12, ветка «с отличием» никогда не выполнится: 18 тоже не меньше 12.

Практика 2.5.1. Добавьте ветку для отрицательного балла: score < 0 возвращает "ошибка в данных". Проверьте на списке [-1, 11, 12, 18].

Критерий 2.5.1: для 18, 15, 20 и 11 выводятся «зачёт с отличием», «зачёт», «зачёт с отличием», «нужна доработка». Для -1 — «ошибка в данных».

2.5.2. Цикл for

for перебирает элементы последовательности. range(1, 11) даёт числа от 1 до 10: правая граница не входит.

Ячейка — continue:

total = 0
for n in range(1, 11):
    if n % 2 == 0:
        continue
    total += n
print("сумма нечётных 1..10 =", total)

continue сразу переходит к следующему числу и не выполняет остаток тела цикла.

Ячейка — отбор:

passed = []
for row in students:
    if row["score"] >= 12:
        passed.append(row["name"])
print(passed)

Практика 2.5.2. Соберите список имён тех, кому нужна доработка, через ту же функцию grade. Ожидается ["Глеб"].

Критерий 2.5.2: сумма нечётных равна 25, в passed три имени: Анна, Борис, Вера.

2.5.3. break и while

break заканчивает цикл целиком. while повторяется, пока условие истинно. У цикла while должен быть шаг, который когда-нибудь сделает условие ложным.

Ячейка:

found = None
for row in students:
    if row["score"] == 20:
        found = row["name"]
        break
print("первый с баллом 20:", found)

Ячейка — накопление до порога:

total = 0
index = 0
while index < len(students) and total < 40:
    total += students[index]["score"]
    index += 1
print("сумма:", total, "взято записей:", index)

Анна и Борис дают 33, вместе с Верой — 53. Цикл остановится на третьей записи: сумма впервые станет не меньше 40.

Практика 2.5.3. Найдите первое имя с баллом меньше 12 и остановите цикл через break. Если такого нет, напечатайте "все сдали".

Критерий 2.5.3: найденное имя — Глеб; во втором примере сумма 53 и взято 3 записи.

2.5.4. Вложенное ветвление

Внутри ветки можно снова спросить условие. Для двух независимых признаков удобнее два последовательных if, а не глубокая лесенка.

Ячейка:

def comment(score: int, attempts: int) -> str:
    if score >= 12:
        if attempts == 1:
            return "сдано с первой попытки"
        return "сдано не с первой попытки"
    return "пока не сдано"

print(comment(18, 1))
print(comment(15, 2))
print(comment(11, 1))

Практика 2.5.4. Расширьте таблицу полем attempts: Анна — 1, Борис — 2, Вера — 1, Глеб — 3. Напечатайте имя и результат comment.

Критерий 2.5.4: три строки выше печатают «сдано с первой попытки», «сдано не с первой попытки», «пока не сдано». У Глеба в таблице — «пока не сдано».

2.5.5. Тернарный оператор

Тернарный оператор — выражение с двумя вариантами: значение если условие истинно, иначе другое значение. Его пишут там, где выбор помещается в одну строку. Несколько порогов по-прежнему удобнее записывать через if / elif.

Ячейка:

def short_grade(score: int) -> str:
    return "зачёт" if score >= 12 else "нужна доработка"

for student in students:
    print(student["name"], short_grade(student["score"]))

То же выражение можно сразу положить в список:

labels = ["зачёт" if student["score"] >= 12 else "доработка" for student in students]
print(labels)

Практика 2.5.5. Одной тернарной записью получите список "ошибка" для отрицательного балла и "балл принят" для остальных. Проверьте на [-1, 11, 18].

Критерий 2.5.5: у Анны, Бориса и Веры метка «зачёт», у Глеба — «нужна доработка». Список labels равен ["зачёт", "зачёт", "зачёт", "доработка"]. Для [-1, 11, 18] практика даёт ["ошибка", "балл принят", "балл принят"].

2.5.6. Сопоставление match

match сравнивает значение с образцами сверху вниз и выполняет первую подошедшую ветку. Образец case _ принимает всё, что не подошло раньше. Условие к уже пойманному значению пишут через if.

Ячейка:

def band(score: int) -> str:
    match score:
        case n if n < 0:
            return "ошибка в данных"
        case 18 | 19 | 20:
            return "верх диапазона"
        case n if n >= 12:
            return "зачёт"
        case _:
            return "нужна доработка"

for score in (20, 18, 15, 11, -1):
    print(score, band(score))

Ветка 18 | 19 | 20 срабатывает только на эти три числа. Балл 15 до неё не доходит и попадает в n if n >= 12.

Практика 2.5.6. Добавьте сопоставление канала. Для значений "поиск", "реклама" и "письмо" верните короткие подписи, для любого другого текста — "другой канал". Проверьте на списке ["поиск", "письмо", "визит"].

Критерий 2.5.6: пары выше печатают «верх диапазона», «верх диапазона», «зачёт», «нужна доработка», «ошибка в данных». Неизвестный канал получает подпись «другой канал».

2.5.7. Моржовый оператор

Оператор := присваивает значение имени и тут же отдаёт это значение в выражение. Им пользуются, когда одно и то же значение нужно и проверить, и сохранить. Обычное = по-прежнему стоит отдельной строкой.

Ячейка:

passed = []
for student in students:
    if (score := student["score"]) >= 12:
        passed.append((student["name"], score))
print(passed)

Скобки вокруг score := ... нужны, чтобы присваивание относилось только к баллу, а сравнение >= 12 шло уже с сохранённым числом.

То же имя доступно в списковом включении:

high = [student["name"] for student in students if (score := student["score"]) >= 18]
print(high)

Практика 2.5.7. Пройдите students циклом while и остановитесь на первом балле меньше 12. Балл читайте моржовым оператором. Напечатайте имя этого слушателя и сам балл.

Критерий 2.5.7: passed содержит Анну, Бориса и Веру с баллами 18, 15 и 20. high равен ["Анна", "Вера"]. Практика останавливается на Глебе и балле 11.

Типовые ошибки

Симптом Что проверить
Все баллы от 12 получают «с отличием» Более строгая проверка >= 18 стоит выше >= 12
Сумма нечётных равна 30 В сумму попали и чётные: continue стоит после total += n
Цикл while не заканчивается В теле нет изменения переменной из условия
break не срабатывает Условие сравнивает строку с числом или смотрит не тот ключ словаря
Балл 15 попадает в «верх диапазона» Ветка 18 | 19 | 20 стоит раньше общего условия n >= 12, и 15 в неё не входит
match не запускается Нужен Python 3.10 или новее: python --version
