2.9 Отладка

Цель: останавливать программу в нужной строке, смотреть переменные, перехватывать ожидаемую ошибку через try / except / else и проверять условие оператором assert.

Опора: расширение Python и интерпретатор ./.venv/Scripts/python.exe. Рабочая папка VS Code — корень курса.

Итоговые артефакты (в папке module-2-9/):

Файл Назначение
debug_demo.py Скрипт, на котором ставят точки останова
bug_average.py Скрипт с ошибкой, которую находят отладчиком
lab29-debug.md Короткая заметка: что было в переменных на остановке

Подготовка

Проверьте интерпретатор: Ctrl+Shift+P → Python: Select Interpreter → ./.venv/Scripts/python.exe. Отладчик запускает тот интерпретатор, который выбран в статусной строке.

2.9.1. Точка останова

Создайте module-2-9/debug_demo.py:

def grade(score: int) -> str:
    if score >= 18:
        label = "зачёт с отличием"
    elif score >= 12:
        label = "зачёт"
    else:
        label = "нужна доработка"
    return label


def main():
    scores = [18, 15, 9]
    for score in scores:
        result = grade(score)
        print(score, result)


if __name__ == "__main__":
    main()
  1. Щёлкните слева от номера строки result = grade(score). Появится красная точка.
  2. Откройте Run and Debug (Ctrl+Shift+D) и запустите Python File.
  3. Выполнение остановится до этой строки. В панели Variables найдите score.
  4. Continue (F5) переходит к следующей остановке. Пройдите все три числа.

Практика 2.9.1. В lab29-debug.md запишите три значения score, которые видели на остановке, и три строки из отладочной консоли.

Критерий 2.9.1: остановка срабатывает три раза, в консоли есть пары 18 зачёт с отличием, 15 зачёт, 9 нужна доработка.

2.9.2. Шаг внутрь и шаг через

На строке вызова grade(score) доступны два шага:

Клавиша Команда Куда переходит
F10 Step Over Выполняет вызов целиком и остаётся в main
F11 Step Into Входит в первую строку grade
Shift+F11 Step Out Выполняет функцию до return и возвращается к вызывающему коду

Практика 2.9.2. Поставьте точку на строке вызова. Нажмите F11. Внутри grade дойдите до присваивания label клавишей F10. Для балла 9 в Variables должно появиться label со значением «нужна доработка». Затем Shift+F11 вернёт вас в цикл.

Критерий 2.9.2: в заметке записано, что при score == 9 переменная label равна «нужна доработка» ещё до выхода из функции.

2.9.3. Условная точка останова

Останавливаться на каждом элементе неудобно, если ошибка только в одном значении. Правый щелчок по красной точке → Edit Breakpoint → выражение score < 12.

Запустите отладку снова. Остановка будет только для 9. Значения 18 и 15 выполнятся без паузы.

Практика 2.9.3. Смените условие на score == 15, запустите ещё раз и убедитесь, что пауза одна и в переменной именно 15. После проверки условие можно снять.

Критерий 2.9.3: при условии score < 12 отладчик останавливается один раз.

2.9.4. Поиск ошибки

Создайте module-2-9/bug_average.py. Среднее считается неверно: сумма делится не на число элементов.

def average(values: list[int]) -> float:
    total = 0
    for value in values:
        total += value
    return total / (len(values) - 1)


def main():
    scores = [18, 15, 20, 11]
    print("среднее:", average(scores))


if __name__ == "__main__":
    main()

Верное среднее — (18 + 15 + 20 + 11) / 4 = 16. Скрипт печатает другое число.

  1. Поставьте точку останова на строке return.
  2. Запустите отладчик.
  3. В Watch добавьте выражения total, len(values) и len(values) - 1.
  4. Сравните делитель с числом оценок.

Практика 2.9.4. Исправьте делитель на len(values). Запустите файл обычным образом, без отладчика:

python module-2-9\bug_average.py

Критерий 2.9.4: до исправления в Watch видно деление на 3 при четырёх оценках. После исправления скрипт печатает среднее: 16.0.

2.9.5. Отладочная консоль

Пока программа стоит на точке останова, панель Debug Console выполняет выражения в этом месте. Это не терминал: команды cd здесь не работают.

На остановке внутри average наберите:

values
total / len(values)

Второе выражение показывает среднее, не меняя файл. Так проверяют догадку до правки кода.

Критерий 2.9.5: консоль на остановке печатает список из четырёх баллов и число 16.0.

2.9.6. try, except и else

try выполняет код, в котором ошибка ожидаема. except ловит конкретный тип ошибки. Ветка else выполняется только если исключения не было: в неё ставят действия, которые имеют смысл лишь после успешного разбора.

Добавьте в ноутбук ячейку:

def read_score(text: str) -> int | None:
    try:
        score = int(text)
    except ValueError:
        print("не число:", text)
        return None
    else:
        print("разобрано:", score)
        return score

for text in ("18", "нет", "9"):
    read_score(text)

Строка "нет" не прерывает цикл: int выбрасывает ValueError, его забирает except. Для "18" и "9" печатается «разобрано».

Практика 2.9.6. Разберите список ["18", "", "15"]. Пустую строку поймайте тем же except ValueError и напечатайте "пустой балл". Остальные значения верните числами.

Критерий 2.9.6: для "18" и "9" есть строка «разобрано», для "нет" — «не число», цикл доходит до конца. В практике пустая строка даёт «пустой балл», а не обрыв ячейки.

2.9.7. assert

assert проверяет условие, которое в этом месте программы уже обязано быть истинным. Если оно ложно, Python поднимает AssertionError и показывает текст после запятой. Это проверка для разработчика, а не замена if при разборе данных пользователя.

def average(values: list[int]) -> float:
    assert values, "список оценок пуст"
    assert all(score >= 0 for score in values), "балл не может быть отрицательным"
    return sum(values) / len(values)

print(average([18, 15, 20, 11]))

Пустой список или отрицательный балл останавливают функцию на assert, до деления выполнение не доходит. Такой сбой удобно ловить точкой останова на строке assert: в Variables видно values.

Практика 2.9.7. Вызовите average([]) и average([18, -1]) в отдельных ячейках. Для каждого вызова запишите в lab29-debug.md текст AssertionError. Затем поймайте отрицательный балл через try / except AssertionError и напечатайте "данные отклонены".

Критерий 2.9.7: average([18, 15, 20, 11]) печатает 16.0. Пустой список и балл -1 дают AssertionError с разными текстами. После except ячейка печатает «данные отклонены» и не обрывается.

Симптом Что проверить
Отладчик использует не .venv Статусная строка и Python: Select Interpreter
Точка серая и не срабатывает Файл сохранён, запущена именно эта копия, строка выполняется
F10 не входит в grade Для входа нужна F11
