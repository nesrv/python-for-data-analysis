2.7.1. Функция как объект

Функция — значение. Её можно положить в переменную и вызвать уже по новому имени.

Ячейка:

def say_hello():
    print("Hello")

def say_goodbye():
    print("Good Bye")

message = say_hello
message()
message = say_goodbye
message()

Имя без скобок — сама функция. Скобки — вызов.

Ячейка — операция в переменной:

def add(a, b):
    return a + b

def multiply(a, b):
    return a * b

operation = add
print(operation(5, 6))
operation = multiply
print(operation(5, 6))

Критерий 2.7.1: сначала печатается Hello, затем Good Bye. Вызовы дают 11 и 30.

2.7.2. Функция как параметр и как результат

Функцию передают аргументом. Функция может вернуть другую функцию: вызывающий код выбирает операцию номером, а не копирует ветки if.

Ячейка:

def do(a, b, op):
    return op(a, b)

print(do(5, 5, add))
print(do(5, 5, multiply))

add и multiply должны остаться в памяти с предыдущей ячейки. Если ядро перезапускали, выполните их снова.

Ячейка — фабрика:

def subtract(a, b):
    return a - b

def select_operation(choice):
    if choice == 1:
        return add
    if choice == 2:
        return subtract
    return multiply

operation = select_operation(1)
print(operation(10, 6))
operation = select_operation(2)
print(operation(10, 6))
operation = select_operation(3)
print(operation(10, 6))

Тот же приём со словарём. Неизвестное имя возвращает функцию-заглушку, а не падает с KeyError:

calc = {
    "plus": lambda x, y: x + y,
    "minus": lambda x, y: x - y,
    "power": pow,
}

def action(name, dictionary):
    if name in dictionary:
        return dictionary[name]
    return lambda *args: "NO CALC"

print(action("plus", calc)(5, 4))
print(action("power", calc)(3, 3))
print(action("square", calc)(1, 1))

Критерий 2.7.2: do печатает 10 и 25. Фабрика печатает 16, 4 и 60. Словарь даёт 9, 27 и NO CALC.

2.7.3. Каррирование

Каррирование разбивает функцию нескольких аргументов на цепочку функций одного аргумента. Внешняя функция запоминает приветствие и возвращает функцию для имени.

Ячейка:

def greet_curried(greeting):
    def greet(name):
        return greeting + ", " + name
    return greet

hello = greet_curried("Hello")
print(hello("Игорь"))
print(hello("Роман"))
print(greet_curried("Hi")("Сергей"))

Практика 2.7.3. Сделайте scale(factor), которая возвращает функцию одного числа. scale(10)(3) должно дать 30.

Критерий 2.7.3: три приветствия печатаются как Hello, Игорь, Hello, Роман и Hi, Сергей. Практика даёт 30.

2.7.4. lambda

lambda — функция из одного выражения, без имени и без return. Её пишут там, где отдельный def только мешает чтению: в map, filter и sorted. Несколько строк в lambda записать нельзя.

Ячейка:

words = "Hello Python from Russia".split()
lengths = list(map(lambda word: len(word), words))
squares = list(map(lambda x: x ** 2, [1, 2, 3, 4, 5]))
print(lengths)
print(squares)

Тот же список квадратов даёт включение [x ** 2 for x in [1, 2, 3, 4, 5]]. lambda нужна, когда функцию надо передать, а не когда строится новый список на месте.

Критерий 2.7.4: длины равны [5, 6, 4, 6], квадраты — [1, 4, 9, 16, 25].

2.7.5. Сортировка по ключу

sorted и list.sort сравнивают не сами элементы, а значения, которые вернула функция key.

Ячейка:

numbers = [4, 3, -10, 1, 7, 12]
print(sorted(numbers, key=lambda x: x % 2))

cities = ["Москва", "Тверь", "Смоленск", "Псков", "Рязань"]
print(sorted(cities, key=len))
print(sorted(cities, key=lambda city: city[-1]))

Чётные числа дают ключ 0 и идут раньше нечётных. Города выстраиваются по длине, затем по последней букве.

Ячейка — вложенные записи:

books = (
    ("Евгений Онегин", "Пушкин А.С.", 200),
    ("Муму", "Тургенев И.С.", 250),
    ("Мастер и Маргарита", "Булгаков М.А.", 500),
    ("Мертвые души", "Гоголь Н.В.", 190),
)
print(sorted(books, key=lambda book: book[2]))

Практика 2.7.5. Мешки заданы парами «вес, стоимость». Отсортируйте их по стоимости за килограмм, а при равной цене — по меньшему весу.

bags = [
    [47, 470],
    [50, 600],
    [60, 480],
    [45, 540],
    [30, 300],
]
ordered = sorted(bags, key=lambda bag: (bag[1] / bag[0], bag[0]))
print(ordered)

Критерий 2.7.5: первая книга в отсортированном списке — «Мертвые души» за 190. Мешки идут так: [60, 480], [30, 300], [47, 470], [45, 540], [50, 600]. У первого мешка цена 8 за килограмм, у двух следующих — 10, и более лёгкий стоит раньше.

2.7.6. all и any

all истинен, когда истинны все элементы. any истинен, когда истинен хотя бы один. Пустая строка, 0 и пустой список ложны.

Ячейка:

print(all([True, True, True]))
print(all([True, False, True]))
print(any([0, "", [1]]))

Поле крестиков-ноликов — один список из девяти клеток. Строка выиграна, если все три клетки равны "x":

field = ["x", "x", "o", "x", "x", "x", "o", "x", "x"]
rows = [
    all(cell == "x" for cell in field[0:3]),
    all(cell == "x" for cell in field[3:6]),
    all(cell == "x" for cell in field[6:9]),
]
print(rows)

Практика 2.7.6. Поле сапёра — список из 100 нулей. Поставьте мину в клетку 4: field[4] = "*". any должен вернуть True. Уберите мину и убедитесь, что результат стал False.

Критерий 2.7.6: выиграна только вторая строка, список строк равен [False, True, False]. С миной any даёт True.

2.7.7. map, filter и reduce

map применяет функцию к каждому элементу. filter оставляет элементы, для которых функция истинна. reduce сворачивает последовательность в одно значение. map и filter возвращают итераторы: для печати их превращают в список.

Ячейка:

numbers = [1, 2, 4, 5, 7, 8, 10, 11]
even = list(filter(lambda n: n % 2 == 0, numbers))
print(even)

cities = ("Москва", "Рязань", "Смоленск", "Тверь", "Томск")
print(list(filter(str.isalpha, cities)))
print(list(filter(lambda name: name[-1] == "а", cities)))

Ячейка — reduce:

from functools import reduce

values = [1, 2, 3, 4, 5]
print(reduce(lambda x, y: x + y, values, 0))
print(reduce(lambda x, y: x * y, values, 1))

Начальное значение 0 для суммы и 1 для произведения задаёт результат пустого списка и первый шаг свёртки.

Практика 2.7.7. Посчитайте площадь квартиры: к каждой комнате примените произведение длины и ширины, затем сверните площади суммой.

rooms = [
    {"name": "кухня", "length": 6, "width": 4},
    {"name": "комната 1", "length": 5.5, "width": 4.5},
    {"name": "комната 2", "length": 5, "width": 4},
    {"name": "комната 3", "length": 7, "width": 6.3},
]
areas = map(lambda room: room["length"] * room["width"], rooms)
print(reduce(lambda x, y: x + y, areas, 0))

Критерий 2.7.7: чётные числа — [2, 4, 8, 10]. На «а» заканчиваются Москва и Рязань. Сумма ряда равна 15, произведение — 120. Площадь квартиры равна 112.85.

2.7.8. Комбинации

itertools строит сочетания и размещения, не храня все промежуточные списки заранее. Результат — итератор, его печатают через list или *.

Ячейка:

from itertools import combinations, product

letters = "ГОД"
print(list(combinations(letters, 2)))
words = ["".join(item) for item in product(letters, repeat=2)]
print(words)

combinations не повторяет букву внутри пары и не меняет порядок на обратный. product берёт каждый элемент с каждым, включая повторы.

Практика 2.7.8. Сколько слов длины 6 можно составить из букв Г, О, Д, если слово начинается с согласной и буквы можно повторять. Согласные здесь — Г и Д. Посчитайте через product и проверьте формулой 2 * 3 ** 5.

Критерий 2.7.8: пар из трёх букв без повтора и без перестановки — три: ГО, ГД, ОД. Слов длины 6 — 486.

Симптом Что проверить
