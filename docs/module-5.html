5.1.1. Создание, чтение и запись

Pandas подключают строкой import pandas as pd. Дальше в этом уроке — как завести свои данные и как взять данные, которые уже лежат в файле.

Создание данных

В pandas два основных объекта: DataFrame и Series.

DataFrame — это таблица. В ней массив отдельных записей, у каждой записи есть значение. Запись стоит на пересечении строки и столбца.

Конструктор pd.DataFrame принимает словарь. Ключ словаря — имя столбца, значение — список записей этого столбца. Так собирают новую таблицу чаще всего.

Без параметра index метки строк — это просто счётчик 0, 1, 2, … Иногда этого хватает. Часто метки нужны свои. Список меток строк называется Index, его передают параметром index.

Series — последовательность значений. Если DataFrame — таблица, то Series — список, и его можно создать из обычного списка. По сути Series — один столбец DataFrame. Метки строк задают тем же параметром index. Имени столбца у Series нет: есть одно общее имя name. DataFrame удобно представлять как несколько Series, склеенных по общему индексу.

Список под каждым столбцом читается сверху вниз: первый элемент — первая строка, второй — вторая. У «Яблок» и «Бананов» списки одной длины, иначе таблица не соберётся.

Ячейка:

import pandas as pd

# Одна строка и два столбца. Ключ словаря — имя столбца.
fruits = pd.DataFrame({"Яблоки": [30], "Бананы": [21]})

# Две строки. index подписывает строки: без него были бы метки 0 и 1.
fruit_sales = pd.DataFrame(
    {"Яблоки": [35, 41], "Бананы": [21, 34]},
    index=["Продажи 2017", "Продажи 2018"],
)

# Series — один столбец. name подписывает всю серию, а не отдельный столбец.
ingredients = pd.Series(
    ["4 стакана", "1 стакан", "2 крупных", "1 банка"],
    index=["Мука", "Молоко", "Яйца", "Тушёнка"],
    name="Ужин",
)

print(fruits.shape, fruit_sales.shape)  # (строки, столбцы)
print(fruit_sales)
print(ingredients)

fruits — одна строка и два столбца. fruit_sales — две строки, и метки строк заданы явно. У ingredients имя серии — «Ужин».

Критерий 5.1.1а: формы (1, 2) и (2, 2). В «Продажи 2018» яблок 41. Имя серии — Ужин, первая метка — Мука.

Чтение файла

Собрать DataFrame или Series руками удобно для примера. В работе почти всегда данные уже где-то лежат. Самый простой вид такого файла — CSV. Если открыть его как текст, видно таблицу, в которой значения разделены запятыми. Отсюда имя: comma-separated values, значения через запятую.

pd.read_csv читает такой файл в DataFrame. У функции больше тридцати необязательных параметров. В books.csv первый столбец — уже готовый номер строки, у него пустой заголовок. Сам по себе pandas этот столбец индексом не считает и заводит новый индекс с нуля, а номер остаётся обычным столбцом. Параметр index_col=0 говорит взять готовый столбец в индекс.

Размер получившейся таблицы смотрят атрибутом shape: число строк и число столбцов. Первые строки показывает head. По умолчанию head берёт пять строк, аргумент уменьшает или увеличивает это число.

Ячейка:

# Первый столбец файла — готовые номера 0…11. Без index_col он остаётся обычным столбцом.
plain = pd.read_csv("module-5/data/books.csv")
# Тот же файл, но номер строки забираем в индекс. Столбцов становится на один меньше.
books = pd.read_csv("module-5/data/books.csv", index_col=0)
print(plain.shape, books.shape)
print(books.head(3))  # три первые книги, не вся таблица

Критерий 5.1.1б: plain имеет форму (12, 9), books — (12, 8). Индекс books начинается с 0, первая книга — «Тихий двор».

Запись и чтение из базы

to_csv записывает DataFrame в CSV. По умолчанию в файл попадает и индекс. index=False индекс выбрасывает: при повторном чтении метки «Год 1» и «Год 2» уже не восстановить.

Ячейка:

animals = pd.DataFrame(
    {"Коровы": [12, 20], "Козы": [22, 19]},
    index=["Год 1", "Год 2"],
)
# Индекс пишется в файл вместе со столбцами. index=False стёр бы «Год 1» и «Год 2».
animals.to_csv("module-5/data/cows_and_goats.csv")
# При чтении тот же столбец снова ставим индексом, иначе метки лет станут обычным столбцом.
loaded = pd.read_csv("module-5/data/cows_and_goats.csv", index_col=0)
print(loaded)

Критерий 5.1.1в: файл module-5/data/cows_and_goats.csv читается обратно. В «Год 1» коров 12 и коз 22.

Ту же таблицу можно прочитать не из CSV, а запросом к PostgreSQL. Контейнер pg18-course уже запущен, база в нём называется course, пользователь — student. В терминале эта база открывается так:

docker exec -it pg18-course psql -U student -d course

Из ноутбука ходят на тот же сервер снаружи контейнера: хост localhost, порт 5432, пароль student. Строка подключения та же, что в модуле 3. create_engine открывает соединение, pd.read_sql выполняет запрос и возвращает DataFrame.

В базе лежит таблица authors: Иванова, Петров, Смирнова.

Ячейка:

import sqlalchemy as sa

# Та же база, что открывает docker exec ... psql -U student -d course
engine = sa.create_engine(
    "postgresql+psycopg://student:student@localhost:5432/course"
)
# SELECT * — все столбцы таблицы authors. Результат сразу становится DataFrame.
authors = pd.read_sql(sa.text("SELECT * FROM authors ORDER BY author_id"), engine)
print(authors)

Критерий 5.1.1г: в authors 3 строки и 2 столбца. Имена — Иванова, Петров, Смирнова.

5.1.2. Индексация, выборка и присваивание

Почти любая операция с таблицей начинается с того, что из DataFrame или Series достают нужные значения. Этот урок — как делать это быстро.

Обычные способы обратиться к столбцу

В Python к полю объекта обращаются как к атрибуту: у книги могло бы быть поле title, и его читали бы как book.title. Столбец DataFrame устроен так же. Словарь читают квадратными скобками, и столбец тоже: books["city"]. Оба способа дают одну и ту же Series. Скобки нужны, когда в имени есть пробел или другое имя, которое нельзя записать как атрибут: books.city name уже не сработает, а books["city name"] сработает.

Series похожа на словарь. Чтобы дойти до одного значения, скобки ставят ещё раз: books["city"][0]. Для дальнейшей работы у pandas есть свои операторы, loc и iloc.

Выбор по позиции

Первый способ — выбор по числовой позиции в таблице. Его делает iloc.

И loc, и iloc пишут сначала строку, потом столбец. В обычном Python чаще наоборот: сначала столбец, потом строка. Поэтому строку через iloc достать проще, чем столбец. Столбец берут так: books.iloc[:, 0]. Двоеточие само по себе значит «всё». Вместе с другими границами оно задаёт диапазон. books.iloc[:3, 0] — столбец city из первых трёх строк. books.iloc[1:3, 0] — вторая и третья записи. В iloc можно передать список позиций: books.iloc[[0, 1, 2], 0]. Отрицательное число считает с конца: books.iloc[-5:] — последние пять строк.

Выбор по метке

Второй способ — выбор по метке индекса. Его делает loc. Важна метка, а не место строки в таблице. Город первой книги читают так: books.loc[0, "city"].

iloc проще устроен: он не смотрит на индекс и обращается с таблицей как с матрицей, список списков, в который входят по номеру позиции. loc пользуется метками. Когда метки что-то значат, с loc короче. Например, сразу несколько столбцов: books.loc[:, ["title", "city", "score"]].

Между loc и iloc есть расхождение в срезах. iloc следует обычному правилу Python: левый край входит, правый нет. 0:10 — это позиции 0…9, десять строк. loc включает оба края. 0:10 — это метки 0…10, одиннадцать строк. Так сделано потому, что меткой бывает и строка. Если индекс — «Яблоки» … «Картофель», срез «от яблок до картофеля» удобнее записать df.loc["Яблоки":"Картофель"], чем придумывать метку сразу после последней нужной. Когда индекс — обычные числа 0, 1, 2, …, разница легко теряется: iloc[0:10] вернёт 10 строк, loc[0:10] — 11. Чтобы получить 10 строк через loc, правую метку уменьшают на единицу: loc[0:9]. В остальном правила loc и iloc совпадают.

Индекс можно сменить

Сила выбора по метке — в самих метках. Индекс не закреплён навсегда. set_index("title") ставит названием книги метку строки и возвращает новую таблицу. Исходный books при этом не меняется. Метод нужен, когда для таблицы находится индекс удачнее текущего.

В ячейке шесть разных отборов. Их удобно читать по одной строке: столбец, одна ячейка, целая строка, срез, список меток, несколько столбцов.

Ячейка:

desc = books["description"]             # столбец аннотаций, это Series
first_description = desc.iloc[0]        # первая аннотация: позиция 0
first_row = books.iloc[0]               # первая строка целиком, тоже Series
first_descriptions = books["description"].iloc[:10]  # позиции 0…9, десятая не входит
sample_books = books.loc[[1, 2, 3, 5, 8]]  # ровно эти метки, не диапазон
places = books.loc[[0, 1, 10], ["city", "genre", "reviewer"]]
head_cols = books.loc[:7, ["title", "genre"]]  # метки 0…7 включительно, восемь строк

print(type(desc).__name__)
print(first_description)
print(len(first_descriptions), sample_books.shape, places.shape, head_cols.shape)
# Один и тот же текст среза: iloc отбрасывает правый край, loc его оставляет.
print("iloc", len(books.iloc[0:10]), "loc", len(books.loc[0:10]))
# Новая таблица с названием вместо номера. Исходный books остаётся с числовым индексом.
print(books.set_index("title").index[0])

set_index("title") возвращает новую таблицу, где метка строки — название. Исходный books от этого не меняется.

Критерий 5.1.2а: desc имеет тип Series. Первая аннотация — «Спокойный сюжет без спешки». Длины и формы: 10, (5, 8), (3, 3), (8, 2). Срез iloc[0:10] содержит 10 строк, срез loc[0:10] — 11. После set_index первая метка — «Тихий двор».

Выбор по условию

До сих пор строки брали по устройству самой таблицы: по номеру или по метке. Чтобы задать вопрос к данным, нужно условие.

books.city == "Казань" даёт Series из True и False по каждой строке. Эту Series передают в loc, и остаются только истинные строки. Второе условие присоединяют амперсандом &, если нужны оба, или вертикальной чертой |, если достаточно одного. Каждое сравнение берут в скобки: у & приоритет выше, чем у ==.

Два готовых отбора стоит запомнить. isin оставляет значения из заданного списка: город «Москва» или «Казань». notnull (и парный isnull) отмечает ячейки, которые заполнены или пусты. books.loc[books.price.notnull()] убирает книгу без цены.

Присваивание

В обратную сторону, записать данные в таблицу, так же прямо. Константа заполняет весь новый столбец одним значением. Последовательность той же длины заполняет ячейки по порядку.

Ячейка:

kazan = books.loc[books.city == "Казань"]
kazan_strong = books.loc[(books.city == "Казань") & (books.score >= 90)]
wide = books.loc[(books.city == "Казань") | (books.score >= 90)]
two_cities = books.loc[books.city.isin(["Москва", "Казань"])]
priced = books.loc[books.price.notnull()]
print(kazan.shape[0], kazan_strong.shape[0], wide.shape[0], two_cities.shape[0], priced.shape[0])

marked = books.copy()
marked["critic"] = "все"
marked["index_backwards"] = range(len(marked), 0, -1)
print(marked.loc[0, "critic"], int(marked.loc[0, "index_backwards"]), int(marked.loc[11, "index_backwards"]))

books.copy() нужен, чтобы новые столбцы остались в marked. Дальнейшие разделы продолжают работать с исходными восемью столбцами books.

Практика 5.1.2. В markdown запишите пять чисел из print и объясните, почему books[0] не отдаёт первую строку, а books.iloc[0] отдаёт.

Критерий 5.1.2б: числа 3, 2, 7, 8, 11. В marked у строки 0 стоит «все» и 12, у строки 11 стоит 1.

5.1.3. Сводные функции и отображения

Выбрать нужные строки ещё не значит получить данные в том виде, в каком они нужны для ответа. Иногда столбец приходится пересчитать. Этот урок — сводки по столбцу и отображения, которые переводят значения в другой вид.

Сводные функции

У pandas много коротких сводок. Они заново укладывают данные так, чтобы по ним было видно главное. describe собирает такую сводку и смотрит на тип столбца. Для числа это количество, среднее, стандартное отклонение, минимум, квартили и максимум. Для текста вывод другой: сколько непустых значений, сколько разных, какое встречается чаще всех и сколько раз.

Если нужна одна цифра, для неё обычно есть отдельная функция. mean — среднее. median — медиана. unique — список разных значений. value_counts — те же значения и сколько раз каждое встретилось. Пустые ячейки value_counts не считает.

Ячейка:

print(books.score.describe())
print(books.reviewer.describe())
print(books.city.value_counts())
median_score = books.score.median()
centered_price = books.price - books.price.mean()
print(median_score, round(float(centered_price.iloc[0]), 2))
print(round(float((books.score - books.score.mean()).iloc[0]), 2))
print((books.city + " - " + books.genre).iloc[0])

Отображения

Отображение — функция, которая берёт один набор значений и переводит его в другой. Так из имеющихся данных получают новый столбец или приводят столбец к нужному виду.

Чаще всего используют два метода. map проще. Ему передают функцию одного значения Series, и он возвращает новую Series, где каждое значение уже пересчитано. Вычесть среднее из каждой оценки можно так: books.score.map(lambda p: p - books.score.mean()).

apply делает то же для целой строки DataFrame. Функция получает строку и возвращает строку. Если вызвать apply с axis="index", функция получит не строку, а столбец.

И map, и apply возвращают новый объект. Таблицу, к которой их применили, они не меняют. Если после пересчёта оценок снова открыть первую строку books, в ней по-прежнему исходная оценка.

Многие обычные отображения уже встроены и работают быстрее map и apply. Вычитание числа из столбца pandas понимает само: слева много значений, справа одно, значит это одно нужно вычесть из каждого. То же с двумя Series одинаковой длины. Город и жанр склеивают так: books.city + " - " + books.genre. Обычные операторы Python, включая >, < и ==, устроены так же. Ветвление по условию сложением и вычитанием не выразить: для него остаются map и apply.

Пустой город в склейке даёт пустой результат, поэтому для проверки взята первая строка, где город заполнен.

Критерий 5.1.3а: медиана оценки 89. Цена первой книги выше средней цены на 15.45. Оценка первой книги выше средней оценки на 1.17. Склейка первой строки — «Москва - роман». В describe по рецензентам 11 непустых значений, 3 разных имени, чаще всех Анна (4 раза). По городам: Москва 5, Казань 3, Новосибирск 3.

Дальше два отображения на наших книгах. map считает, в скольких аннотациях есть слово. apply ставит книге число звёзд по правилу, в котором участвуют и город, и оценка. Поиск подстроки различает регистр: «Детектив» в «Старом мосте» не совпадает с «детектив».

Ячейка:

# Отношение «оценка / цена». idxmax возвращает метку строки-максимума, не само число.
# Пустая цена даёт NaN, и такая строка в максимум не берётся.
bargain_idx = (books.score / books.price).idxmax()
bargain_title = books.loc[bargain_idx, "title"]

# map вызывает функцию для каждой аннотации. True в sum считается как 1, False как 0.
# Регистр важен: «Детектив» с большой буквы в «детектив» не входит.
n_humor = books.description.map(lambda text: "юмор" in text).sum()
n_detective = books.description.map(lambda text: "детектив" in text).sum()
words = pd.Series([n_humor, n_detective], index=["юмор", "детектив"])

def stars(row):
    # Казань получает 3 звезды при любой оценке. Дальше смотрим только оценку.
    if row.city == "Казань":
        return 3
    if row.score >= 95:
        return 3
    if row.score >= 85:
        return 2
    return 1

# axis="columns": в stars приходит строка таблицы. Сам books от этого не меняется.
star_ratings = books.apply(stars, axis="columns")
print(bargain_idx, bargain_title)
print(words)
print(star_ratings.value_counts().sort_index())

idxmax возвращает метку строки, где отношение «оценка / цена» наибольшее. Деление на пустую цену даёт NaN, и idxmax такую строку пропускает.

Правило звёзд: Казань — 3 звезды при любой оценке; иначе 3 при оценке от 95, 2 при оценке от 85, иначе 1.

Практика 5.1.3. В markdown запишите название книги с лучшим отношением оценки к цене и одно предложение, почему «Старый мост» не попал в подсчёт слова «детектив».

Критерий 5.1.3б: метка 9, название «Последний трамвай». Слово «юмор» встречается 4 раза, «детектив» — 3. Звёзды: единица у 2 книг, двойка у 6, тройка у 4.

5.1.4. Группировка и сортировка

Отображение пересчитывает столбец по одному значению. Часто нужно сначала собрать строки в группы и уже с группой что-то сделать. Для этого есть groupby. В том же уроке — индекс из нескольких уровней и сортировка.

Разбор по группам

value_counts мы уже вызывали. То же самое записывается длиннее: books.groupby("score").score.count(). groupby собирает строки с одинаковой оценкой, затем по столбцу score считает, сколько раз значение встретилось. value_counts — короткая запись этой пары.

К группе применяют те же сводки, что и к целому столбцу: min, max, mean, size. Группу можно мыслить как срез таблицы, в котором остались только строки с одним значением ключа. Этот срез доступен через apply: функция получает кусок таблицы и возвращает то, что нужно. Например, первое название в каждом жанре — books.groupby("genre")["title"].apply(lambda titles: titles.iloc[0]). Это первая строка группы в порядке файла, не книга с максимальной оценкой.

Группировать можно сразу по нескольким столбцам. Лучшее название внутри пары «город и жанр» выбирают так: внутри группы берут строку, где score максимален, и из неё читают title.

agg запускает несколько функций за один проход. Для цены по жанру это минимум и максимум сразу: books.groupby("genre").price.agg(["min", "max"]).

Пустая метка группы в сводку не входит. Книга без города отсутствует в groupby(["city", "genre"]), книга без handle отсутствует в группировке по отметке.

Индекс из нескольких уровней

До сих пор у индекса был один уровень. groupby по двум столбцам часто возвращает MultiIndex: уровней несколько, и чтобы достать значение, нужны две метки. У такого индекса есть свои методы, которых нет у обычного. Чаще всего нужен один: reset_index возвращает уровни в обычные столбцы.

Сортировка

После группировки строки идут в порядке индекса, а не в порядке посчитанного значения. sort_values сортирует по значению столбца. По умолчанию порядок по возрастанию, меньшие числа сверху. ascending=False ставит большие числа первыми. sort_index сортирует по метке индекса и принимает те же аргументы. В sort_values можно передать список столбцов: сначала один, при равенстве — следующий.

Ячейка отвечает на несколько вопросов подряд. Каждый вопрос — своя группировка, предыдущую она не портит.

  1. Сколько книг получили одну и ту же оценку.
  2. Какое название стоит первым в файле внутри жанра.
  3. Какая книга лучшая по оценке в паре «город, жанр».
  4. Сколько отзывов у каждой отметки и какая средняя оценка у рецензента.
  5. Какой минимум и максимум цены у жанра, если поставить сверху самый дорогой минимум.
  6. Сколько книг в паре «город, жанр», если пустой город не считать.

Ячейка:

# Длинная запись value_counts: группы с одинаковой оценкой, затем число строк в группе.
print(books.groupby("score").score.count())
# iloc[0] — первая строка группы в порядке файла, не строка с максимальной оценкой.
print(books.groupby("genre")["title"].apply(lambda titles: titles.iloc[0]))

# Группа — маленький DataFrame. idxmax ищет в нём метку максимальной оценки.
best_name = books.groupby(["city", "genre"]).apply(
    lambda df: df.loc[df.score.idxmax(), "title"]
)
# Две метки сразу: уровень города и уровень жанра.
print(best_name.loc[("Москва", "роман")])

written = books.groupby("handle").size()  # сколько строк у каждой отметки
# Лучшая оценка при каждой цене, затем цены по возрастанию.
best_score = books.groupby("price")["score"].max().sort_index()
# min и max за один проход, два столбца в ответе.
extremes = books.groupby("genre").price.agg(["min", "max"])
# Сначала по минимуму цены, при равенстве — по максимуму. Оба по убыванию.
sorted_genres = extremes.sort_values(by=["min", "max"], ascending=False)
mean_score = books.groupby("reviewer").score.mean().round(2)
# size считает и пустые ячейки внутри группы. sort_values ставит большие группы сверху.
pair_counts = books.groupby(["city", "genre"]).size().sort_values(ascending=False)

print(written)
print(sorted_genres)
print(mean_score)
print(int(pair_counts.sum()), int(pair_counts.max()))
print(int(best_score.loc[150.0]))  # лучшая оценка среди книг ценой 150

# agg по двум ключам даёт MultiIndex. reset_index возвращает город и жанр в столбцы.
counted = books.groupby(["city", "genre"]).description.agg(["count"])
print(type(counted.index).__name__)
flat = counted.reset_index().sort_values(by="count", ascending=False)
print(flat.head(3))

Критерий 5.1.4: первое название романа — «Тихий двор». Лучший роман Москвы по оценке — «Дом у парка». Отметки: @anna 4, @boris 4, @vera 3. После сортировки по минимуму цены сверху жанр детектив (минимум 280, максимум 900). Средние оценки: Анна 89.50, Борис 86.75, Вера 92.33. В парах «город, жанр» 11 книг, самая большая пара имеет размер 2. При цене 150 максимальная оценка 83. Индекс counted имеет тип MultiIndex.

5.1.5. Типы данных и пропущенные значения

Этот урок — как узнать, в каком типе pandas держит столбец, и как найти и заменить значения.

Типы

Тип столбца DataFrame или Series называется dtype. У одного столбца его читают свойством dtype, у всех столбцов сразу — свойством dtypes.

Тип говорит, как значение хранится. float64 — число с плавающей точкой на 64 бита. int64 — целое того же размера. Текстовый столбец в этом окружении имеет dtype str: отдельного числового типа для строк нет.

Где преобразование имеет смысл, столбец переводят в другой тип функцией astype. Она возвращает новый столбец и старый не переписывает. Свой dtype есть и у индекса.

Пропущенные значения

Пустая ячейка записывается как NaN, not a number. По технической причине такой NaN всегда имеет тип float64. Поэтому столбец price с одной пустой ценой целиком становится float64, хотя остальные цены целые.

Пустые ячейки находит pd.isnull (и парный pd.notnull). То же самое делает метод столбца isnull. Замену пустоты делает fillna. Ей можно подставить одно и то же значение во все пустые ячейки, например «Неизвестно». Другая стратегия — взять ближайшее непустое значение ниже по таблице. Её выполняет bfill.

replace меняет одно конкретное непустое значение на другое и тоже возвращает новый столбец. Им же закрывают пропуски, которые в файле уже записаны словом-заглушкой: «Неизвестно», «не указано», «ошибка».

Ячейка:

print(books.score.dtype)   # целое: пустых оценок нет
print(books.price.dtype)   # дробное: одна пустая цена переводит весь столбец в float64
print(books.title.dtype)   # текст
print(books.index.dtype)   # метки строк тоже имеют тип
# Новый столбец из текста. books.score остаётся числом, astype исходный столбец не переписывает.
point_strings = books.score.astype(str)
print(point_strings.iloc[0])

Критерий 5.1.5а: score имеет тип int64, price — float64, title — str, индекс — int64. Первая оценка в текстовом виде — строка 90.

Ячейка:

# isnull даёт True и False. В сумме True считается как 1, поэтому это число пустых цен.
n_missing_prices = int(books.price.isnull().sum())
# fillna подставляет слово только в пустые ячейки и возвращает новый столбец.
per_city = books.city.fillna("Неизвестно").value_counts()
print(n_missing_prices)
print(per_city)
# Строка 5 — «Речной свет», город пуст. bfill берёт ближайший непустой город ниже.
print(books.city.bfill().iloc[5])
# replace тоже возвращает новый столбец. В books отметка @anna остаётся прежней.
fresh = books.handle.replace("@anna", "@anna_books")
print(int((fresh == "@anna_books").sum()), books.loc[0, "handle"])

У «Речного света» город пуст. Следующая непустая ячейка города — «Москва» у «Красного шарфа», её и ставит bfill.

Практика 5.1.5. В markdown одной фразой запишите, почему тип price — float64, хотя в файле цены выглядят целыми.

Критерий 5.1.5б: пустая цена одна. После fillna город «Неизвестно» встречается 1 раз, Москва — 5. bfill в строке 5 даёт «Москва». replace ставит @anna_books в 4 строках, а в исходном books у строки 0 по-прежнему @anna.

5.1.6. Переименование и объединение

Столбцы, индекс и подписи часто приходят с именами, которые для ответа не годятся. Этот урок — как их переименовать и как собрать вместе несколько таблиц.

Переименование

rename меняет метки индекса, имена столбцов или и то и другое. Столбец score можно назвать оценка: books.rename(columns={"score": "оценка"}). Что именно менять, задают параметром index или columns. Удобнее всего передать словарь «старое имя — новое имя». Тем же словарём меняют отдельные метки строк: books.rename(index={0: "первая", 1: "вторая"}).

Столбцы переименовывают часто, отдельные метки строк — редко. Чтобы заменить индекс целиком, обычно удобнее set_index из раздела 5.1.2.

И у индекса строк, и у индекса столбцов есть собственное имя. Его меняет rename_axis. Например, индекс строк можно назвать «книги», а индекс столбцов — «поля».

Объединение

Иногда строки и столбцы лежат в разных DataFrame или Series, и их нужно собрать. Три основных способа, от простого к сложному: concat, join и merge. Почти всё, что делает merge, короче записывается через join, поэтому ниже — первые два.

concat получает список таблиц и склеивает их вдоль оси. Он подходит, когда таблицы разные, а набор столбцов общий. Остатки двух магазинов ставят друг под другом: pd.concat([center, station]). Если указать другую ось, склейка пойдёт по столбцам, а не по строкам.

join соединяет таблицы с общим индексом и подтягивает столбцы правой таблицы к строкам левой. Перед вызовом общий ключ ставят в индекс через set_index. Если в обеих таблицах есть столбцы с одинаковыми именами, к ним добавляют суффиксы параметрами lsuffix и rsuffix. Если имена уже различаются, суффиксы не нужны. У изданий столбец называется publisher, у склада — copies, поэтому editions.join(stock) обходится без суффиксов. В результате остаются строки левой таблицы.

Ячейка:

# Словарь «старое имя — новое». Остальные столбцы не трогаем. books остаётся прежним.
renamed = books.rename(columns={"genre": "жанр", "city": "город"})
# Имя самого индекса строк и имя списка столбцов. Это не переименование столбцов.
reindexed = books.rename_axis("книги", axis="rows").rename_axis("поля", axis="columns")
print("жанр" in renamed.columns, reindexed.index.name, reindexed.columns.name)

center = pd.read_csv("module-5/data/shop_center.csv")
station = pd.read_csv("module-5/data/shop_station.csv")
# Столбцы называются одинаково, поэтому строки просто ставятся друг под другом.
combined = pd.concat([center, station])
print(combined.shape, int(combined.qty.sum()))

# Общий ключ — book_id. Пока он столбец, join по нему не соединит таблицы.
editions = pd.read_csv("module-5/data/editions.csv").set_index("book_id")
stock = pd.read_csv("module-5/data/stock.csv").set_index("book_id")
# Слева издания, справа остаток. Строки берутся из левой таблицы.
catalog = editions.join(stock)
print(catalog)
print(int(catalog.copies.sum()))  # пустой остаток в сумму не входит

# Если столбец qty есть в обеих таблицах, без суффикса имена столкнутся.
# Здесь одна и та же книга в двух магазинах, столбцы различаем суффиксами.
one_title = pd.DataFrame({"qty": [4]}, index=pd.Index(["Тихий двор"], name="title"))
other_shop = pd.DataFrame({"qty": [1]}, index=pd.Index(["Тихий двор"], name="title"))
print(one_title.join(other_shop, lsuffix="_центр", rsuffix="_вокзал"))

В editions четыре издания. На складе есть книга 8, но издания с таким book_id нет, поэтому join её не показывает. У книги 4 издание есть, остатка нет: в copies остаётся пусто. sum пустую ячейку пропускает.

Практика 5.1.6. В markdown запишите book_id, у которого в каталоге пустой остаток, и сумму copies.

Критерий 5.1.6: столбец жанр есть в renamed. Имя индекса — книги, имя столбцов — поля. Склейка магазинов имеет форму (4, 2), сумма qty равна 14. В каталоге 4 строки, пустой остаток у book_id 4, сумма copies равна 16.
