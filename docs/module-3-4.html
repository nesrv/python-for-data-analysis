3.4 Нормализация данных. Форматирование данных

Цель: привести поля одной таблицы к общим правилам: текст без лишних пробелов, числа и даты в одном виде, категории в одном словаре, числовой столбец на общей шкале.

Опора: pandas из модуля 3.1, таблица без явных дублей из модуля 3.3. Ядро Jupyter — ./.venv/Scripts/python.exe. Рабочая папка VS Code — корень курса.

Файл Назначение
data/orders_raw.csv Заказы в разнобое: пробелы, запятая в сумме, разные даты и подписи
lab34-format.ipynb Ноутбук с разбором и приведением полей

Форматирование меняет запись значения, но не его смысл: " 1 200,50 " и 1200.5 — одна сумма. Нормализация в этом занятии — приведение к одному правилу: одна шкала у чисел, одно написание у категории.

3.4.1. Исходная таблица

Создайте module-3-4/data/orders_raw.csv в кодировке UTF-8:

order_id,city,amount,ordered_at,channel
1,  Москва ,"1 200,50",12.03.2026,Поиск
2,казань,980.00,2026-03-13,реклама
3,МОСКВА,"2 450,00",13/03/2026,ПОИСК
4,Тула,1500,2026/03/14,письмо

Одна и та же сущность записана по-разному. Город встречается как Москва и МОСКВА. Сумма то с пробелом и запятой, то с точкой. Дата приходит в трёх шаблонах. Канал отличается регистром.

Ячейка:

import pandas as pd

raw = pd.read_csv("module-3-4/data/orders_raw.csv", encoding="utf-8", dtype=str)
print(raw.dtypes)
print(raw)

dtype=str нужен, чтобы pandas не угадывал числа и даты до ваших правил.

Критерий 3.4.1: четыре строки, все столбцы имеют тип object или string, кириллица читается.

3.4.2. Текст

Пробелы по краям и регистр не меняют город, но мешают группировке. Категорию приводят к одному написанию.

frame = raw.copy()
frame["city"] = frame["city"].str.strip().str.lower()
frame["channel"] = frame["channel"].str.strip().str.lower()
print(frame["city"].tolist())
print(frame["channel"].unique().tolist())

Практика 3.4.2. Замените канал словарём подписей: поиск → search, реклама → ads, письмо → email. Неизвестное значение оставьте как есть.

channel_map = {"поиск": "search", "реклама": "ads", "письмо": "email"}
frame["channel"] = frame["channel"].map(channel_map).fillna(frame["channel"])
print(frame["channel"].tolist())

Критерий 3.4.2: города — москва, казань, москва, тула. Каналы — search, ads, search, email.

3.4.3. Числа

Сумма в файле — текст. Пробел отделяет тысячи, запятая отделяет дробную часть. Перед float пробелы убирают, запятую меняют на точку.

frame["amount"] = (
    frame["amount"]
    .str.replace(" ", "", regex=False)
    .str.replace(",", ".", regex=False)
    .astype(float)
)
print(frame["amount"].tolist())
print(frame["amount"].sum())

Критерий 3.4.3: значения 1200.5, 980.0, 2450.0, 1500.0. Сумма равна 6130.5.

3.4.4. Даты

pandas умеет разобрать несколько шаблонов, если передать format="mixed" и день раньше месяца там, где запись неоднозначна. Для этой таблицы день стоит первым в 12.03.2026 и 13/03/2026.

frame["ordered_at"] = pd.to_datetime(
    frame["ordered_at"],
    format="mixed",
    dayfirst=True,
)
print(frame["ordered_at"].dt.strftime("%Y-%m-%d").tolist())

В результат сохраняют одну строковую форму ГГГГ-ММ-ДД, а не исходный разнобой.

frame["ordered_at"] = frame["ordered_at"].dt.strftime("%Y-%m-%d")
print(frame["ordered_at"].tolist())

Критерий 3.4.4: даты равны 2026-03-12, 2026-03-13, 2026-03-13, 2026-03-14.

3.4.5. Общая шкала суммы

После форматирования суммы всё ещё лежат в рублях и плохо сравниваются с другим показателем, если тот измерен в других единицах. Минимакс переводит столбец в отрезок от 0 до 1: минимум становится 0, максимум становится 1.

low = frame["amount"].min()
high = frame["amount"].max()
frame["amount_norm"] = (frame["amount"] - low) / (high - low)
print(frame[["amount", "amount_norm"]])

Исходную сумму не удаляют: нормированное поле добавляют рядом. Минимум 980 получает 0, максимум 2450 получает 1.

Практика 3.4.5. Проверьте руками норму для 1500: (1500 - 980) / (2450 - 980). Сверьте с ячейкой.

Критерий 3.4.5: в amount_norm есть 0 и 1. Для суммы 1500 норма примерно 0.3537. Столбец amount на месте.

3.4.6. Сохранение

from pathlib import Path

ready = frame[["order_id", "city", "amount", "amount_norm", "ordered_at", "channel"]]
out = Path("module-3-4/data/orders_ready.csv")
ready.to_csv(out, index=False, encoding="utf-8")

check = pd.read_csv(out, encoding="utf-8")
print(check)
print("сумма", check["amount"].sum())

Критерий 3.4.6: файл читается повторно, сумма amount равна 6130.5, даты в виде 2026-03-12 и соседних дней, каналы на английских кодах из словаря.

Типовые ошибки

Симптом Что проверить
Сумма стала 1200 без копеек или NaN Запятую меняют на точку после удаления пробелов, не наоборот
Москва и МОСКВА остались разными Нет strip или lower до группировки
Дата 12.03.2026 стала 3 декабря В to_datetime не передан dayfirst=True
Деление на ноль в норме В столбце одно и то же число: минимум равен максимуму
В CSV снова числа-строки с запятой В файл пишут frame после astype(float), а не исходный raw

После занятия слушатель отдельно приводит запись полей к одному виду и отдельно, если шкала нужна для сравнения, кладёт число в отрезок от 0 до 1, не стирая исходное значение.
